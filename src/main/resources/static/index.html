spring-ai@demo:~/features$ ./dev-console

Developer-Konsole

Triggert die Backend-Endpunkte der Dev-Features direkt aus dem Browser. Die Structured-Output-Analyse wird grafisch ausgewertet.

00_gate_decider — route.sh

Gate-Decider · KI-Router

Ein Eingang fuer alles: Die KI entscheidet, welches Feature zustaendig ist, und delegiert an dessen Endpunkt. Zeigt die gewaehlte Route und die durchgereichte Antwort. Ruft GET /api/gateway auf. (Benötigt einen gültigen API-Key.)

04_structured_output — ticket-analyze.sh

Structured Output · Ticket-Analyse

Freitext rein → typisierte Analyse (Kategorie, Priorität, Sentiment). Ruft POST /api/tickets/analyze auf. (Benötigt einen gültigen API-Key.)

06_tool_calling — product-catalog.sh

Tool Calling · Produktkatalog

Das Modell ruft bei Bedarf den Katalog-Service auf. Ruft GET /api/tools auf. (Benötigt einen gültigen API-Key.)

07_rag — knowledge-base.sh

RAG · Wissensspeicher

Antwort auf Basis abgerufener Dokumente. GET /api/rag (Antwort, API-Key) bzw. GET /api/rag/sources (nur Quellen, ohne API-Key).

14_db_query — ask-database.sh

DB-Abfrage · Frag deine Datenbank

Natuerlichsprachliche Aggregations-Frage gegen den gesamten eGK-Datenbestand (alle Tabellen). Das Modell nutzt gepruefte Abfrage-Tools bzw. ein abgesichertes SELECT. Ruft GET /api/db/ask auf. (Benötigt einen gültigen API-Key + befüllte DB.)
